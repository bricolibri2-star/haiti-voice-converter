# application android / backend / conversion vocale

Projet base pour la création d’une application de conversion vocale voix-à-voix.

## État actuel

- interface Android préparée
- backend FastAPI prêt à recevoir les fichiers audio
- point d’entrée de conversion ajouté
- moteur de conversion réel à brancher
