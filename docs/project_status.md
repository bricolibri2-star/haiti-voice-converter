# État du projet

- Android : interface de sélection d’un audio source et de plusieurs fichiers de référence, paramètres visuels et consentement.
- Backend : API FastAPI de validation et d’orchestration vers un adaptateur configurable.
- Le backend n’invente pas de résultat si aucun moteur n’est connecté.
- L’application Android n’est pas encore raccordée à l’API ; l’APK complet et la conversion réelle ne sont donc pas livrés.
- Les fichiers résultat nécessitent une politique de rétention avant toute mise en ligne.
