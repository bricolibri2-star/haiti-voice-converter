## Données vocales et validation

Consultez [docs/voice_data_and_evaluation.md](docs/voice_data_and_evaluation.md) pour le protocole de collecte consentie auprès de locuteurs haïtiens natifs, la préparation des références et les critères d’évaluation. La quantité seule ne garantit pas la fidélité ; le moteur et la qualité des enregistrements doivent être testés avec les locuteurs concernés.
